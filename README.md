# Morrow & Moss — Animated Café Landing Page

A premium-style, responsive café landing page built with plain HTML, CSS, and JavaScript. No build tools or frameworks required.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, keyframe animations, and reduced-motion support
- `script.js` — mobile navigation, reveal-on-scroll, and scroll progress

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
Upload all three files (`index.html`, `style.css`, `script.js`) to the **root** of your GitHub repository. In **Settings → Pages**, select branch `main` and folder `/(root)`.

## Before using for a real business
Replace sample menu items and prices, the sample email (`hello@example.com`), and any placeholder business information. The page uses externally hosted Google Fonts and Unsplash photos, so those assets require an internet connection.
